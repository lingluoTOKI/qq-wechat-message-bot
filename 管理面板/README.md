## 当前额度口径（2026-10-23）

用户已选择赠送token保护。1500万总额，平台截图剩余14,996,456，初始化已用3,544。之后累加接口usage返回的实际token；请求发出前按输入字节及最大输出预留，返回有效用量后替换预留。失败或未知用量保留预留。SQLite持久化，重启不清零。旧金额账本保留但不再控制个人提醒。

## 排障

- **页面拒绝连接**：确认黑色控制台窗口还在（隧道随窗口存活），窗口关了 = 隧道断了，重新双击 bat
- **隧道建立失败**：看 logs\tunnel.log（密钥、服务器可达性、端口占用）
- **面板起不来**：看 logs\panel.log
- **VC++ 弹窗（node-pty 断言）**：WorkBuddy 终端组件的已知 bug，点「忽略」即可；
  请从资源管理器双击 bat，不要在 WorkBuddy 终端里运行

- 历史摘要区分已读取文字、筛选成功、读取为空、分析失败；显示缓存复用和实际请求数，保留旧结果供直接查看。抽样范围仍非完整聊天记录。

### 可访问历史回顾与文件保存（2026-10-24）

在“历史摘要”统一提供“近期摘要／全量回顾／文件保存”。全量回顾按 QQ 群聊和好友接口、本机微信可见会话逐页读取；每页最多50条，文字分批分析。接口未提供的旧记录、删除记录、过期文件无法恢复；不包含图片、语音和附件正文识别，不承诺账号全部历史。

- 点击开始才读取历史并使用现有智谱模型；成功处理的消息按内容、来源和规则版本记录，重复回顾复用结果。进度及文件候选在本地数据库中加密保存，重启后暂停，点击继续恢复。
- 每轮约10万token预估保护、最多100页，达到后暂停，继续开启下一轮；实际用量可能与预估不同，原有赠送额度保护仍生效。紧急新消息可在批次间处理。接口失败单列，不作为“没有重要信息”。
- 事项进入今日待办／参考资料，历史任务本身不发送群消息或私聊。日常私聊通知保持原规则。
- 文件只列为候选，由用户勾选确认后上传至设置中的 QQ 群（默认 **917905372**）的群文件，每次最多10个；候选每页200个，可翻页。相同来源和相同文件标识去重；仅凭文件名提示相关性，不鉴定正文。
- 微信文件需在本机已下载，按原文件名和大小核对；QQ文件需接口返回有效下载地址。接口返回群文件编号才标记保存，超时／无回执标记待确认，避免自动重复上传。群成员可以查看已上传文件。聊天原记录不会被清除。
- 已用隔离数据库验证分页、复用、暂停续读、固定群目标和上传超时；浏览器模拟转存并检查390px布局。未用真实私聊、真实文件上传或付费模型执行测试。首次真实历史与群文件上传需由用户在面板发起验证。

| 功能 | 入口与行为 |
| --- | --- |
| 历史范围 | 历史摘要 → 全量回顾 → 选择扫描范围：QQ/微信、群聊/私聊、重点/手选/全部、北京时间起止日期；默认重点群和最近7天。空日期不限对应边界。 |
| 规模预览 | 范围窗口“读取会话列表”只查询可访问来源，不调用模型；展示已识别会话数，消息总量未知。每页50条、文字约6000字一批，实际页数随读取统计，包含分页重叠。 |
| 文件独立扫描 | 文件保存 → 独立扫描文件；只登记附件，不调用模型。文件可按名称、来源文字、平台、日期筛选，分页查看。 |
| 三级分流 | 仅本人相关的 urgent 事项即时私聊；important/useful 待办每日汇总；reference 仅留面板。个人或群设“仅每日汇总”时覆盖即时提醒。分类仍依赖模型判断，不保证零误判。 |
| 统一送达 | 运行状态 → 通知送达合并近期私聊和文件上传记录，含目标、时间、内容/文件名、结果；明确失败可重试，未知结果须核对，文件重试再次确认当前群。即时与历史触发送达共用互斥锁，防止并发重发。 |
| 按群关注 | 关注群聊 → 关注内容，可写500字偏好；仅影响此来源，空白沿用个人设置。原关注级别与每日汇总策略继续有效。 |
| 结果纠正 | 待办详情、参考资料“纠正结果”：无关、很重要、指定重复对应事项、撤销。无关/重复收起并取消尚未发送的通知和提醒；重要置为待办并收藏，不立即推送。后续分析参考来源最近8条反馈，精确标题可直接应用纠正；不自动重跑旧记录。撤销不重发已取消通知或恢复已取消的定时提醒。 |
| 任务管理 | 显示读取/等待模型/分析阶段，支持暂停续读、跳过会话、结束、重试失败会话。操作在当前请求结束后生效；已提取事项与缓存保留。列表发现失败仍可能需要新建任务重新读取。 |
| 内容去重 | 对已下载的本机微信文件流式计算SHA-256，按内容和目标群登记成功/不确定上传。同内容改名不会向同群重复上传；发送前重新检查。QQ远程附件未下载，仍仅按文件标识去重，界面明确标注。内容指纹不是文件正文的重要性鉴定。 |
| 期限提醒 | 待办详情确认北京时间截止时间，再选择提前1小时/1天；替换此事项原提醒，要求提醒时间在未来90天内。完成事项取消未发出的提醒；电脑离线后恢复会补提醒。 |
