# 卫戍运营助手轻量扩展

v1.6.0：增加机器人通用功能。提醒、规则答疑与群聊格式提醒不调用模型；明确请求的链接摘要及图片识别调用现有模型，受预算保护。

## 通用功能与当前预算

- 当前已生效预算：每日 CNY 0.10、每月 CNY 3，超额停止后续模型请求，不影响规则功能。费用按已记录用量，可能存在在途超额。
- /提醒 明天 09:00 内容、/提醒 每天 21:00 内容、/提醒 每周 21:00 内容；/提醒列表、/取消提醒 编号。支持“今晚9点提醒开黑”等明确时间句式；没有时刻会要求补充。北京时间，120秒轮询；发到原会话，不跨平台猜测私聊ID。每人每会话10条、全局100条，完成7天清理。
- 每周提醒表示从下次指定时刻起每7天。到期发送失败最多尝试2次，第二次至少10分钟后；失败后停止该条，不宣称成功。周期提醒仅成功后推进，不积压补发所有错过周期。仅提醒列表可见发送状态。
- /总结链接 https://公开网页 或“总结这个链接 https://...”才读取网页并调用模型；不自动处理所有链接。拒绝内网/本机/元数据地址、账号口令URL、非80/443端口、文件下载；每次解析DNS校验公网地址，重定向逐次验证，最多128KiB正文、8000字符送模。
- 图片与“提取文字”“识图文字”“识别报错”同条发送，只处理第一张官方QQ附件；引用旧图、本地文件及任意用户提供图片URL不读取。使用当前模型的视觉能力，若模型不支持视觉需另行配置，未调用付费视觉API验证。
- 摘要/识图每人每会话60秒冷却，成本插件不可用或已超额拒绝，走标准LLM链路并去除工具，不直接绕过成本护栏发请求。
- 现有群管规则保留；额外连续相同内容3次/120秒只发一次提醒、10分钟冷却，并阻止该重复消息继续进入模型。可疑链接仅检查格式特征，不声称已扫描或认定恶意，不自动禁言/踢人。
- /新人报到、/欢迎 给出使用入口。当前官方QQ适配器未找到成员入群事件处理，自动入群欢迎未实现，不应对外宣称支持。

本版独立检查覆盖提醒权限/周期/去重/无具体时间、成本护栏缺失拒绝、重复消息冷却、URL协议/认证/端口/本机地址拒绝。没有发送真实测试群消息或调用模型测试摘要/视觉。

## 招募、确认与维护

- /退出开黑 编号：仅本群已加入者可退出，原有效期不延长；满员名单保留至原30分钟期限，退出后重新开放。/取消开黑 或 /结束开黑 仅处理自己的招募，以群内回复通知登记队友，不擅自推导私聊ID。
- /已解决 编号：仅原反馈者或管理员在原会话确认；多人事件保留各自确认，全部确认或管理员确认才关闭。此前没有 reporter 标识的旧记录只允许管理员确认。不带编号可结束自己的尚未升级求助流程。
- /维护设置 主服 2026-10-24 08:00 30 原因：仅TOKI/管理员私聊可用，北京时间，未来30天内、1—1440分钟，冻结配置的官方群播报目标。10分钟前及开始时提醒，120秒检查可能有约2分钟延迟。
- /维护状态 只读查看；/取消维护 主服 取消；/维护结束 主服 需要健康检查通过才发管理员确认结束通知。只读通知功能，绝无重启、踢人、暂停开局等控制。
- 维护结束后，曾观测到中断且连续两次检查恢复，才自动发布“健康接口恢复响应”；从未中断的维护须手动确认。超过维护结束一天停止轮询，不伪称恢复。通知按目标/阶段去重，失败最多尝试两次；无法保证QQ层超时投递严格一次。

检查覆盖满员/退出/重新开放/取消权限、多人确认与越权拒绝、维护时间校验/健康门槛/无假恢复/回执去重。测试未发送群消息或调用模型。

## 闭环功能

- /故障列表、/故障处理 8位编号 已收到（排查中、已恢复）：仅管理员/TOKI私聊可用。原反馈会话收到状态更新；重复状态取得回执后不重复发送。历史缺少来源的记录不会猜测接收人。
- 失败的管理员通知在原有120秒任务中补发，每条最多两次，首次约2分钟、第二次至少再等10分钟；超过一天或已恢复不再补发。只在有回执后标记成功。超时可能已投递但无回执，无法保证平台层严格仅一次，编号可帮助识别重复。
- 同群同服同类故障30分钟内优先复用已有处理状态，不重复升级。恢复后仍失败可 /报bug 提交新情况。
- /额度状态：复用正在运行的成本插件定价、汇率、统计和预算窗口，不自行计费，缓存30秒。返回已记录的日/月费用、超额停用状态、重置说明；查询失败不冒称正常。
- /加入开黑 编号：不同群不可加入；本人/重复加入不扣名额；明确“缺1—5人”才启用自动满员；加入不延长原30分钟有效期。人数是机器人登记人数，不代表游戏内真实人数。保留 /结束开黑。
- /入门：给出入口、素材指引、玩法、挑战、组队和数据保护提示。

- 已查实费用预算：每日 CNY 1、每月 CNY 10，default_on_exceeded=warn（仅提醒）。本轮没有擅自改为硬停止。

- /今日挑战：只读取 ranking=0，不加载排行榜，短时缓存60秒，显示真实日期和三个目标。

- 故障词触发 FAQ 与最多两轮追问；无关聊天不进入求助流程。

- 官方 API 回执存在才报告通知成功；失败持久保存，管理员私聊 /待处理问题 查看。为避免重复，不自动重试不确定投递。

- 状态查询缓存 30 秒；不安装向量库、本地模型或新调度框架。
