## 2. 优化方案（按优先级）

### P0-1　把 SnowLuma 拓扑一次性查清并固化（半天，零风险）

**目标**：明确"哪条链路负责主动推送"，并让它可验证。

**做法**
1. 在服务器查 astrbot 的 aiocqhttp 适配器配置（`/opt/bot-stack/astrbot/data/cmd_config.json` 里平台的 `ws_reverse_url` / host），确认它连的 snowluma 是**本机**还是**容器**。
2. 查面板 `/api/overview` 里 `services.snowluma` 的容器状态，确认服务器容器是否 `Exited`、是否 `restart:always`。
3. 发一条**测试广播**（走 `_monitor_once` 或直接调 `wukong` 的主动消息接口），看群/私聊是否收到；收不到就抓 astrbot 日志定位是"无权限"还是"未连接"。
4. 结论写进交接手册 §2 的 SnowLuma 段，删掉"待确认"。

**判定分支**
- 若主动推送走**本机**：在面板 00 概览加一块「个人号通道」健康卡（QQ 登录态 + OneBot 连接态），掉线就红。
- 若确实依赖**服务器容器**：用 `--disable-gpu`（或 `LIBGL_ALWAYS_SOFTWARE=1`）拉起，重扫二维码，并加 `restart:always` 防再挂。
- 若两者都不需要：**清理**服务器容器，避免面板继续显示误导信息。

**验收**：一条主动播报能真实送达；面板能一眼看出通道健康。

---

### P0-2　修掉面板「今日要事」卡加载（1–2 小时，低风险）

**目标**：不再出现"永远转圈"。

**做法**
1. `loadOps()` 失败时把 `#matterList` / `#issueList` 的占位文字替换成明确错误（"本地提醒服务未响应（5 秒超时），点击重试"），而不是只写 `opsMessage`。
2. 加载中显示骨架/骨架文案 + 一个「重试」按钮。
3. 把 `panel_server.py` 转发 `/local/operations` 的超时从 5s 调到 12s，并在超时返回结构化 `{ok:false, error:'timeout'}`。
4. 若 `operations` 接口本身慢，给本机提醒服务加**进程内缓存**（30s），面板 30s 轮询时直接命中。

**验收**：断掉本地提醒服务时，页面 12 秒内给出明确错误 + 重试按钮，不再假死。

### P1-2　人格文件发送措辞修正（需拍板，风险中）

**问题**：现人格写"永不生成文件发送"，把表情包/音乐这类内联媒体也误伤了。

**做法**：改成精确表述——"官方频道不能主动发起消息、不传文件附件；表格用 Markdown；表情/音乐等内联媒体正常发"。

**代价**：改人格会**击穿一次前缀缓存**（一次性，之后恢复）。建议**攒到一起改**，别单独为这句话重启。

**验收**：改完发一条带表情的回复 + 一次点歌，确认都正常。

---

### P1-3　监控播报内容升级（2 小时）

**现状**：已有"准入未激活 / 数据过期 / 内存 <200MB / 版本变更 / 重启"。

**建议增加**
- 准入闸**当前生效参数**（minAvailableMB / maxRssMB）随播报带上，方便确认昨天改的值还在。
- swap 使用率（>80% 提醒，比纯 available 更早暴露颠簸）。
- 每日一次**早报**：昨日成本 + 峰值内存 + 对局数 + 异常次数，一条消息看完。

**验收**：收到一条早报，字段齐全。

### P2-1　RAG 知识库（可选，1–2 天）

**前提**：先在 astrbot 配 embedding provider（如智谱 embedding），再把 FAQ / 游玩指引 / 版本文档上传成文档。

**收益**：群友问"手机上怎么装啊""为什么我进不去"这类**非关键词**问法，RAG 能语义召回；关键词直答继续兜底（零 token，优先命中）。

**风险**：引入 embedding 成本（很小）与检索噪声；建议**保留 faq.json 优先级最高**，RAG 只做兜底。

**结论**：非必须。等群规模上来、问答命中率真的不够时再做。

### 明确不做（附理由）

| 事项 | 不做的原因 |
|---|---|
| system_prompt 冻结 / messages 重构 | 风险高，回报是每周几分钱 |
| tools schema 精简 | 会砍功能，且 tools 波动属内禀 |
| 单群 per-session cost override | 需要复杂 budget_overrides，已有 token 预算兜底 |
| 继续调缓存告警阈值 | 已关推送，再调无意义 |
| 给机器人宿主机 shell | prompt injection 直出任意命令，红线 |
