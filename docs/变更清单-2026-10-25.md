## 七、运维约定（自今日起）

1. **纯配置参数**改动：不重启，先改再观察是否即时生效。
2. **插件代码 / schema** 改动：只改文件，报告"需重载 xx 插件"，由用户在面板点重载；不擅自重启容器。
3. **人格 / 记忆库**：直接改数据库，通常无需重启。
4. **Provider / 模型配置**：必须重启，重启前说明原因、代价与影响面。
5. 每次重启会清空 prompt 缓存，**同类改动尽量成批做**。
